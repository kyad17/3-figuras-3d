# Figuras 3D interactivas

## Ejecutar

1. Abrir esta carpeta en Visual Studio Code.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir el enlace de localhost que muestra la terminal.

## Imagen 360 (opcional)

Para mostrar tu propia panorámica 360°, coloca una imagen JPEG llamada **360.jpg** en la carpeta **public** y recarga la página. **Sin esa imagen el proyecto funciona igual**, con fondo oscuro.

## Interacciones

- Octaedro (izquierda): cambia de color al hacer clic.
- Cubo (centro): suma clics.
- Cilindro (derecha): alterna entre sólido y alambre.
- Las tres figuras giran y crecen cuando pasas el cursor sobre ellas.
